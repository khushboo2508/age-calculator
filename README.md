# Age Calculator

A simple and user-friendly Age Calculator built using Python.

## Features

- Calculate exact age in years, months, and days
- Validate date of birth
- Reject future dates
- Handle invalid dates and incorrect formats
- Display the day of birth
- Calculate the next birthday
- Show the number of days remaining until the next birthday
- Allows the user to re-enter the date if the input is invalid

## Technologies Used

- Python
- datetime
- python-dateutil
